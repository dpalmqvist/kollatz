# Lower bounds for the 3x+1 predecessor-set counting function π_a(x) and predecessor-tree growth — literature as of October 2026

Notation: T(n) = n/2 (n even), (3n+1)/2 (n odd); π_a(x) = #{n ≤ x : T^(k)(n) = a for some k ≥ 0}; n_k(a) = #{n : T^(k)(n) = a}. "Refereed" = journal article; "preprint/repo" = arXiv/Zenodo/GitHub/ProofAtlas, not peer reviewed. Where I quote exponents I give them exactly as the source prints them (Lagarias's bibliography sometimes rounds differently from the papers themselves; both are given).

## Key question 1: The historical chain Crandall → Sander → Krasikov → Wirsching → Applegate–Lagarias → Krasikov–Lagarias

### Takeaway
The refereed chain of exponents γ in π_a(x) ≥ x^γ (a ≢ 0 mod 3, x large) is: Crandall 1978 γ ≈ 0.05 (existence of some γ > 0); Sander 1990 γ = 0.30 (= 3/10); Krasikov 1989 γ = 3/7 ≈ 0.43 (k = 2 difference inequalities); Wirsching 1993 γ = 0.48 (k = 3); Applegate–Lagarias 1995 I γ = 0.643 ≈ 0.65 (tree search, depth 30) and II γ = 0.809 ≈ 0.81 (nonlinear program, ~20 000 variables); Krasikov–Lagarias 2003 γ = 0.84 (k = 11). Lagarias's 2010/2021 overview still names 0.84 as the record and states the open problem π_1(x) > c(ε)x^(1−ε).

### Cited Findings
- Crandall, R. E., "On the '3x+1' problem", Math. Comp. 32 (1978), 1281–1292. Lagarias's annotation: Crandall proves the number of odd integers taking exactly h steps to reach 1 is at least a bound of order (log₂x)^h/h!, and "deduces that the function π₁(x) … has π₁(x) > x^c for a positive constant c"; he "does not compute its value, but his proof seems to give c = 0.05" — [Lagarias, Annotated bibliography I (1963–1999), arXiv:math/0309224](https://arxiv.org/abs/math/0309224). Applegate–Lagarias I states "as was first shown by Crandall [3], with γ = .05. Crandall's approach directly studies the tree of preimages of a under T" — [Applegate–Lagarias I, PDF](https://websites.umich.edu/~lagarias/doc/applegateI.pdf).
- Sander, J. W., "On the (3N+1)-conjecture", Acta Arith. 55 (1990), 241–248 (MR 91m:11052). Annotation: "the number of integers ≤ x for which the 3x+1 Conjecture is true is at least x^{3/10}, by extending the approach of Crandall (1978)" — [Lagarias bibliography I, entry 153](https://arxiv.org/abs/math/0309224). AL-I: "Sander [9] strengthened Crandall's approach to obtain γ = .30" — [AL-I PDF](https://websites.umich.edu/~lagarias/doc/applegateI.pdf).
- Krasikov, I., "How many numbers satisfy the 3x+1 Conjecture?", Internat. J. Math. & Math. Sci. 12 (1989), 791–796 (MR 91c:11013). Annotation: "the number of integers ≤ x for which the 3x+1 function has an iterate that is 1 is at least x^{3/7}"; for a ≢ 0 (mod 3), θ_a(x) has at least x^{3/7} elements; "For each fixed k ≥ 2 this paper derives a system of difference inequalities based on information (mod 3^k). The bound x^{3/7} was obtained using k = 2" — [Lagarias bibliography I, entry 105](https://arxiv.org/abs/math/0309224); PDF of Krasikov's paper at [EMIS](https://emis.univie.ac.at/journals/HOA/IJMMS/Volume12_4/362647.pdf). AL-I: "Using these inequalities for k = 2, he obtained γ = .43" — [AL-I PDF](https://websites.umich.edu/~lagarias/doc/applegateI.pdf).
- Wirsching, G. J., "An improved estimate concerning 3N+1 predecessor sets", Acta Arith. 63 (1993), 205–210 (MR 94e:11018). Annotation: "for all a ≢ 0 (mod 3), the set θ_a(x) … has cardinality at least x^{.48}, for sufficiently large x … by exploiting the inequalities of Krasikov (1989)" — [Lagarias bibliography I, entry 182](https://arxiv.org/abs/math/0309224). AL-I: "Wirsching [10] used Krasikov's inequalities with k = 3 to obtain γ = .48" — [AL-I PDF](https://websites.umich.edu/~lagarias/doc/applegateI.pdf).
- Applegate, D., Lagarias, J. C., "Density bounds for the 3x+1 problem I. Tree-search method", Math. Comp. 64 (1995), no. 209, 411–426 (MR 95c:11024). Theorem 1.2 (verbatim from the PDF): "For each a ≢ 0 (mod 3), there is a positive constant c_a such that π_a(x) ≥ c_a x^{.65} for all x ≥ a." The optimised exponent is γ*_30 = .654717 — [AL-I PDF](https://websites.umich.edu/~lagarias/doc/applegateI.pdf); AMS page [S0025-5718-1995-1270612-0](https://www.ams.org/mcom/1995-64-209/S0025-5718-1995-1270612-0/). - Applegate, D., Lagarias, J. C., "Density bounds for the 3x+1 problem II. Krasikov inequalities", Math. Comp. 64 (1995), no. 209, 427–438 (MR 95c:11025). Annotation: "If a ≢ 0 (mod 3), then π_a(x) > x^{.809} for all sufficiently large x. … the inequalities of Krasikov (1989) can be used to construct nonlinear programming problems which yield lower bounds for the exponent γ … The exponent above was derived by computer for such a nonlinear program having about 20000 variables" — [bibliography I, entry 7](https://arxiv.org/abs/math/0309224); AMS page [S0025-5718-1995-1270613-2](https://www.ams.org/mcom/1995-64-209/S0025-5718-1995-1270613-2/); PDF at [Lagarias's site](https://dept.math.lsa.umich.edu/~lagarias/doc/applegateII.pdf). Rigorous asymptotic results are given for the branching process models" — [bibliography I, entry 8](https://arxiv.org/abs/math/0309224).
- Krasikov, I., Lagarias, J. Abstract: computer-aided proof that at least x^{0.84} of the integers below x contain 1 in their forward orbit; the abstract does not mention k = 11 — [arXiv:math/0205002](https://arxiv.org/abs/math/0205002); journal page at [IMPAN](https://www.impan.pl/en/publishing-house/journals-and-series/acta-arithmetica/all/109/3/81918/bounds-for-the-3x-1-problem-using-difference-inequalities). Lagarias's bibliography II: "If a ≢ 0 (mod 3), then π_a(x) > x^{.841} for all sufficiently large x", obtained from the k = 11 nonlinear program — [arXiv:math/0608208](https://arxiv.org/abs/math/0608208).
- Lagarias, J. It remains an open problem to show that for each ε > 0 there exists a positive constant c(ε) such that π_1(x) > c(ε) x^{1−ε}" — [arXiv:2111.02635](https://arxiv.org/abs/2111.02635).
- Korec's complementary "almost all" result (natural density): the set {n : some T^(k)(n) < n^β} has density one for all β > β_c := log 4 / log 3 (cited in AL-I as Korec [4], "An estimation in the 3x+1 problem", Math. Slovaca, preprint 1992) — [AL-I PDF](https://websites.umich.edu/~lagarias/doc/applegateI.pdf).

### Inferences
- The pre-1995 "exponent" results are of two methodologically distinct kinds: Crandall/Sander count the preimage tree directly; Krasikov/Wirsching/AL-II/KL use the mod-3^k difference inequalities. AL-I is the last paper in the tree-search line and explicitly concedes (p. 4) that "Krasikov's inequalities give still better exponents".
- Every refereed exponent ≥ 0.65 is a computer-aided proof (AL-I "unavoidably computer-intensive"; AL-II 20 000-variable NLP; KL 2003 "computer-aided proof"). None of them was formally verified at publication time.

### Gaps
- I did not obtain the full text of Sander 1990, Wirsching 1993 or Krasikov 1989 themselves; exponents come from Lagarias's annotated bibliography and the AL-I introduction, which agree (0.30 vs 3/10; 0.43 vs 3/7; 0.48).
- Lagarias's bibliography quotes AL-I's Theorem 1.1 as (1.299)^k ≤ n_k(a) ≤ (1.361)^k, whereas the paper prints (1.302053)^k ≤ n_k(a) ≤ (1.358386)^k; the paper's numbers should be preferred. Reason for the discrepancy not determined (possibly an earlier preprint version).

## Key question 2: Applegate–Lagarias "Density bounds I": Conjecture A, computed depth, max/min tree-size ratio, later extensions

### Takeaway
Conjecture A in AL-I is *positive density* (π_a(x) ≥ c_a x for all x ≥ a), not a tree-growth statement; the (4/3)^k growth statements are Conjecture B (for n_k(a), due to Lagarias–Weiss) and the stronger Conjectures C and C′ (for the extremal depth-k pruned-tree leaf counts N^−(k), N^+(k)). They computed the extremal vectors for all k ≤ 30; Conjecture C′ asserts C^−(4/3)^k ≤ N^−(k) < N^+(k) ≤ C^+(4/3)^k, i.e. the max/min ratio stays bounded — which they note is *false* for the Lagarias–Weiss branching-process models, and flag as "the first significant deviation" of 3x+1 from randomness. I found no later rigorous extension of the k ≤ 30 extremal computation.

### Cited Findings
- Conjecture A (verbatim): "For each a ≢ 0 (mod 3), there is a positive constant c_a such that π_a(x) ≥ c_a x for all x ≥ a." Preceded by: if a ≡ 0 (mod 3) the preimages are exactly {2^k a}, so π_a(x) grows logarithmically — [AL-I PDF, §1](https://websites.umich.edu/~lagarias/doc/applegateI.pdf).
- Conjecture B (verbatim, attributed to Lagarias–Weiss 1992): "For each a ≢ 0 (mod 3), n_k(a) = (4/3)^{k(1+o(1))} as k → ∞." Lagarias–Weiss proved the *average* of n_k(a) over a ≢ 0 (mod 3) grows like (4/3)^k and, for a not in a cycle, (1/2)(√2)^k ≤ n_k(a) ≤ 2(√3)^k (eq. 1.6) — [AL-I PDF](https://websites.umich.edu/~lagarias/doc/applegateI.pdf); Lagarias, J. C., Weiss, A., "The 3x+1 problem: two stochastic models", Ann. Appl. Probab. 2 (1992), 229–261 (MR 92k:60159) — [bibliography I, entry 112](https://arxiv.org/abs/math/0309224).
- Theorem 1.1 (verbatim): "For any a ≢ 0 (mod 3), and for all sufficiently large k, (1.302053)^k ≤ n_k(a) ≤ (1.358386)^k." "The proof … is unavoidably computer-intensive; in effect it searches all trees of depth 30." — [AL-I PDF](https://websites.umich.edu/~lagarias/doc/applegateI.pdf).
- Computation: "We computed the vectors w^+(k) and w^−(k) for 1 ≤ k ≤ 30; the data for w^−(k) and N^−(k) appear in Table 2.1, and that for w^+(k) and N^+(k) in Table 2.2"; growth rates g^±(k) = N^±(k)^{1/k} tabulated for 1 ≤ k ≤ 30; by (2.8), N^−(k) ≤ (4/3)^k ≤ N^+(k) for all k ≥ 1. "memory was exhausted by the hashtable at k = 21", clones of depth ≥ 21 recomputed as needed; the number of distinct depth-k tree shapes R(k) grows like θ^k with empirically 1.87 < θ < 1.92 — [AL-I PDF, §2](https://websites.umich.edu/~lagarias/doc/applegateI.pdf).
- Conjecture C (verbatim): "Both N^+(k) and N^−(k) are (4/3)^{k(1+o(1))} as k → ∞." Stated as necessary for deriving Conjecture B from Theorem 2.1 (g^−(k) ≤ liminf N*_j(a)^{1/j} ≤ limsup … ≤ g^+(k)); "This conjecture is stronger than Conjecture B, because it concerns extreme values over all trees of depth k". Table 2.3 lists (4/3)^k N^−(k)^{−1} and (4/3)^{−k} N^+(k) — [AL-I PDF](https://websites.umich.edu/~lagarias/doc/applegateI.pdf).
- Conjecture C′ (verbatim): "There are positive constants C^+ and C^− such that C^−(4/3)^k ≤ N^−(k) < N^+(k) ≤ C^+(4/3)^k for all sufficiently large k." Followed by: "It can be proved for the branching process models B[3^j] for j ≥ 2 … that the analogue of Conjecture C is true, but that the analogue of the stronger Conjecture C′ is false, see [2]. That is, 3x+1 trees empirically have a narrower variation of leaf counts than that predicted by such stochastic models. This is the first significant deviation found for the 3x+1 iteration from being as random as possible consistent with obvious constraints. It merits an explanation, and we raise this as an open question." — [AL-I PDF, §2](https://websites.umich.edu/~lagarias/doc/applegateI.pdf).
- Exponent extrapolation: "The largest value we found was γ*_30 = .654717; this proves Theorem 1.2. It is natural to conjecture that (1/k)E[Z^−_k] → log 2 − (1/4) log 3 and that γ*_k → 1 as k → ∞." — [AL-I PDF, §3](https://websites.umich.edu/~lagarias/doc/applegateI.pdf).
- Kontorovich–Lagarias, "Stochastic models for the 3x+1 and 5x+1 problems", arXiv:0910.1944 (in *The Ultimate Challenge*, AMS 2010): defines the tree growth constant δ_3(a) = limsup (1/k) log N_k(a) and states that for each a ≢ 0 (mod 3) it is conjectured to equal log(4/3) (attributed to Lagarias–Weiss); Theorem 6.1: for a uniformly random residue class a (mod 3^{k+1}), a ≢ 0 (mod 3), the expected number of leaves of the pruned depth-k tree is exactly (4/3)^k — [arXiv:0910.1944](https://arxiv.org/abs/0910.1944).
- Sinai, Ya. G., "Statistical (3x+1)-problem", Comm. Pure Appl. Math. 56 (2003), 1016–1028: an upper bound on the number of nodes in 3x+1 trees mod 3^m and an entropy inequality H_m ≥ m log 3 − O(log m) — [bibliography II](https://arxiv.org/abs/math/0608208).

### Inferences
- The "3x+1 Growth Exponent Conjecture" named in the neljaouh repository (see Q6) is the Kontorovich–Lagarias tree-growth-constant conjecture / AL-I Conjecture B–C family, not Conjecture A.
- AL-I's Conjecture C′ (bounded ratio N^+(k)/N^−(k) · (something) — i.e. both extremes within constant factors of (4/3)^k) is exactly the "uniform (4/3)^k growth of pruned trees" the reader asked about; the authors' own data up to k = 30 "support Conjecture C, and even suggest" C′.

### Gaps
- Table values N^−(30), N^+(30) could not be read from the PDF text layer (tables are absent from the extraction); only the derived growth rates 1.302053 and 1.358386 are available.
- I found no refereed or preprint work after 1995 extending the extremal pruned-tree computation beyond depth 30. (The CLAUDE.md note that Applegate–Lagarias later searched trees to depth 60 refers to their *total-stopping-time* paper, arXiv:math/0103054, not to extremal leaf counts.)

## Key question 3: Krasikov–Lagarias 2003 §6 open problem (λ_k → 2 ⇔ exponent 1 − ε): any progress since?

### Takeaway
No refereed progress found. The only authoritative later statement is Lagarias's overview (2010 book / arXiv 2021), which restates the problem as open: show π_1(x) > c(ε)x^{1−ε} for every ε. All 2024–2026 work that pushes the exponent (0.8676 kernel-checked at k = 14; 0.90 via native_decide at k = 18; this project's 0.9203 at k = 21) is finite-k computation and does not address the limit.

### Cited Findings
- Lagarias's annotated bibliography II on KL 2003 describes "the (not yet realized) hope of proving π_a(x) > x^{1−ε} by this approach, taking a sufficiently large k" — [arXiv:math/0608208](https://arxiv.org/abs/math/0608208).
- Lagarias overview: "It remains an open problem to show that for each ε > 0 there exists a positive constant c(ε) such that π_1(x) > c(ε)x^{1−ε}" — [arXiv:2111.02635](https://arxiv.org/abs/2111.02635).
- The 2021 overview, per a search summary, says the lower-bound exponent record "may have an underlying structure involving an infinite family of nonlinear programs of increasing complexity" — [arXiv:2111.02635](https://arxiv.org/pdf/2111.02635) (summary only; exact wording not verified against the PDF text layer).
- Tavares (Aug 2026, preprint) states the KL bound "is a sublinear count with an a-dependent threshold, so it is weaker in both respects than the uniform positive density, of order x/a, that Wirsching's chain targets" — [arXiv:2608.27617](https://arxiv.org/abs/2608.27617).
- msharpe248/collatz (repo) claims "no-go" theorems (`no_finite_certificate`, `no_finite_state_certificate`): a bounded multiplicative potential with fixed contraction over a bounded window cannot certify descent; the README notes these cover bounded weights and bounded windows only — [github.com/msharpe248/collatz](https://github.com/msharpe248/collatz). These concern *descent* certificates, not the λ_k → 2 question.

### Inferences
- The KL §6 question (λ_k → 2, equivalently ρ_k → 1) appears not to have been taken up in print by anyone; a Google-style search on "Krasikov Lagarias difference inequalities 1−ε" returns only the original papers and the 2026 Tavares preprint.
- The neljaouh repository's claimed Lean proof of Conjecture A (positive density, see Q6) would, if its upstream dependency (Mazur's positive-lower-density package) is sound, subsume the 1 − ε problem entirely; this is the only place where the problem is claimed to be settled, and it is unrefereed and AI-generated.

### Gaps
- No citation-index search (MathSciNet/zbMATH/Scopus) was possible; a few papers citing KL 2003 could exist that I did not see. None surfaced in arXiv-oriented searches.

## Key question 4: Wirsching's 1998 book, his 2003 five-condition/three-conjecture programme, and Tavares arXiv:2608.27617

### Takeaway
Confirmed: Wirsching, *The Dynamical System Generated by the 3n+1 Function*, LNM 1681, Springer 1998 (3-adic approach to positive predecessor density); Wirsching, "On the problem of positive predecessor density in 3N+1 dynamics", Discrete Contin. Dyn. Syst. 9 (2003), no. 3, 771–787 (three conjectures ⇒ positive lower density for every a ≢ 0 mod 3). Tavares, R. A., "Wirsching's Positive-Predecessor-Density Program: Proofs of Conjectures 1 and 3", arXiv:2608.27617 (math.GM, v1 27 Aug 2026, 36 pp., unrefereed) claims Conjectures 1 and 3; Conjecture 2 is explicitly left open.

### Cited Findings
- Wirsching, G. J., *The Dynamical System Generated by the 3n+1 Function*, Lecture Notes in Math. 1681, Springer, Berlin 1998 (MR 99g:11027); revised Habilitationsschrift (Eichstätt 1996); "studies the problem of showing that for each positive integer a ≢ 0 (mod 3) a positive proportion of integers less than x iterate to a … develops an interesting 3-adic approach" — [bibliography I, entry 186](https://arxiv.org/abs/math/0309224); Springer page [10.1007/BFb0095985](https://link.springer.com/book/10.1007/BFb0095985).
- Related Wirsching papers: "A Markov chain underlying the backward Syracuse algorithm", Rev. Roumaine Math. Pures Appl. 39 (1994), 915–926 (Markov chain on [0,1] × Z_3^×); "On the combinatorial structure of 3N+1 predecessor sets", Discrete Math. 148 (1996), 265–286; "Balls in constrained urns and Cantor-like sets", Z. Anal. Anwendungen 17 (1998), 979–996 (the Berg–Krüppel integral equation φ(x) = (q/(q−1)) ∫_{qx−q+1}^{qx} φ(y)dy whose solution underlies the "invariant density") — [bibliography I, entries 183, 184, 187](https://arxiv.org/abs/math/0309224).
- Wirsching, G. J., "On the problem of positive predecessor density in 3N+1 dynamics", Discrete Contin. Dyn. Syst. 9 (2003), no. 3, 771–787 (MR 2004f:39028): "proposes an approach to proving positive predecessor density. It formulates three conjectures which, if proved, would establish that result. It develops in more detail aspects of the approach in … Wirsching (1998a)" — [bibliography II](https://arxiv.org/abs/math/0608208). A preprint version ("preliminary note") states the goal "to show that the set of predecessors of a positive integer has positive lower asymptotic density for any positive integer a ≢ 0 mod 3" and that "three unbridged gaps in the argument are formulated as conjectures" — [uni-bielefeld.de/baake/algdyn/posden.pdf](https://www.math.uni-bielefeld.de/baake/algdyn/posden.pdf).
- Tavares, Renato Augusto, "Wirsching's Positive-Predecessor-Density Program: Proofs of Conjectures 1 and 3", arXiv:2608.27617 [math.GM], v1 submitted 27 Aug 2026, 36 pages, MSC 11B83, 39B22, 41A60, 11M06, 60J05, CC BY 4.0, no journal ref. Abstract (paraphrase): Wirsching (2003) reduces uniform positive predecessor density to five conditions grouped into three conjectures; the paper proves Conjectures 1 (path-counting generators relative to their 3-adic Haar average transfer to the "Elka" functions; Theorem 4.3) and 3 (asymptotics near 0 of a base-3 analogue of the Fabius density against Wirsching's comparison function φ_0; the log 3-periodic correction is non-constant, limit e^{H(0)} within Wirsching's comparison class, and the stated asymptotic fails outside that class); with Conjecture 1 the chain reduces to a single condition (⋆3), for which Conjecture 2 "remains open" — [arXiv:2608.27617](https://arxiv.org/abs/2608.27617); HTML at [arxiv.org/html/2608.27617](https://arxiv.org/html/2608.27617).
- Tavares' bibliography cites Mazur's 2026 "certified x^{0.90} lower bounds for Collatz predecessor sets, formalized in Lean" (ProofAtlas) as unrefereed — [arXiv:2608.27617 PDF](https://arxiv.org/pdf/2608.27617).

### Inferences
- Tavares is in math.GM (general mathematics), the category arXiv uses for unclassified/amateur submissions; that plus the absence of a journal reference means it should be treated as a claim pending review.
- Even if Tavares' two conjectures hold, the programme is not complete: (⋆3)/Conjecture 2 remains the gap between the Wirsching chain and positive density.

### Gaps
- I did not verify any of Tavares' proofs, nor find any commentary or citation of it other than its own text.
- The exact statements of Wirsching's five conditions (⋆1)–(⋆5) were not extracted; Tavares' HTML version would give them.

## Key question 5: Tao 2019/2022 "Almost all orbits of the Collatz map attain almost bounded values"

### Takeaway
Tao's theorem is a logarithmic-density statement: for any f : N+1 → R with f(N) → ∞, Col_min(N) ≤ f(N) for almost all N in the sense of logarithmic density; published Forum Math. Pi 10 (2022), e12, 56 pp. The only natural-density strengthening I found is Mazur's ProofAtlas item "Natural-density Collatz descent in logarithmic time" (unrefereed, AI-generated, Lean-checked within ProofAtlas); no refereed natural-density strengthening exists.

### Cited Findings
- Tao, T., "Almost all orbits of the Collatz map attain almost bounded values", arXiv:1909.03562; Forum Math. Pi 10 (2022), Paper No. e12, 56 pp. Abstract: for any f with lim f(N) = +∞, "Col_min(N) ≤ f(N) for almost all N ∈ N+1 (in the sense of logarithmic density)"; the abstract mentions natural density only for Korec's earlier result Col_min(N) ≤ N^θ, θ > log 3/log 4 ≈ 0.7924, "for almost all N (in the sense of natural density)" — [arXiv:1909.03562](https://arxiv.org/abs/1909.03562). One fetch of the abstract page listed versions v1 (8 Sep 2019) … v5 (15 Feb 2022), v6 (6 Jul 2026), v7 (16 Jul 2026); a cached copy showed only up to v5 — [arXiv:1909.03562](https://arxiv.org/abs/1909.03562) (discrepancy noted; check the live page).
- Tao's blog announcement (10 Sep 2019) — [terrytao.wordpress.com](https://terrytao.wordpress.com/2019/09/10/almost-all-collatz-orbits-attain-almost-bounded-values/). A search summary reports a comment there by Mazur describing his predecessor-density extension; not verified by me.
- ProofAtlas "Natural-density Collatz descent in logarithmic time" (Lech Mazur, version 2): claim that for thresholds tending to infinity, natural-density-one many positive starts descend within 436·log N raw Collatz steps; "Accepted in ProofAtlas, Lean checked, 4 reviews"; allows a density-zero exceptional set; does not prove convergence to 1 — [proofatlas.ai/advances](https://www.proofatlas.ai/advances/).
- ProofAtlas "Positive-density Collatz convergence in logarithmic time" (Mazur, manuscript v2.1, 6 Sep 2026): explicit c > 0, X_0 such that at least cX integers n < X reach 1 within 10.46 ln n ordinary steps; "acceptance review open" — [proofatlas.ai/advances](https://www.proofatlas.ai/advances/).
- No 2025–2026 arXiv paper strengthening Tao to natural density was found; arXiv:2603.11066 (E. Chang, Mar 2026, "human–LLM collaboration", conditional reduction to one open hypothesis) is not such a strengthening — [arXiv:2603.11066](https://arxiv.org/pdf/2603.11066v2).

### Inferences
- The CLAUDE.md remark that Mazur "claims natural density 1 for descent (stronger than Tao)" corresponds to the ProofAtlas item above; note the claim is natural-density-one *descent below the start within O(log N) steps*, which is a different (and in the threshold sense weaker, in the density sense stronger) statement than Tao's; it is Lean-checked only inside ProofAtlas's own pipeline and reviewed by AI reviewers.

### Gaps
- Whether Tao's v6/v7 (July 2026) revisions change anything substantive is unknown (not fetched).
- The ProofAtlas natural-density item's Lean trust base (kernel vs native_decide) is "not stated" on the advances page.

## Key question 6: 2024–2026 repositories and preprints (ProofAtlas/Mazur, msharpe248, neljaouh, Menta2357, others)

### Takeaway

## Key question 7: Other 2024–2026 preprints on predecessor density exponents, backward trees, or the transfer-operator / Perron viewpoint

### Takeaway
Very little refereed or credible material: Chunlei Liu arXiv:2512.13760 (math.GM, Dec 2025) claims a counting bound (v2: x^{0.3227}, far below the record; a search summary reports v1 claimed x^{0.946} — unverified) and has been audited as blocked by Menta2357; Hateley (preprints.org, Nov 2025–Jan 2026) studies a backward transfer operator on weighted Banach spaces with a Perron–Frobenius-type result (spectral radius 1, simple eigenvalue, positive invariant density) in a dyadic–triadic multiscale setting; nothing on the Z_3 Haar-measure transfer operator at λ = 2 in the sense of this project was found.
